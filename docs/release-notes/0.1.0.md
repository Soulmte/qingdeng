# 青灯 v0.1.0

首个版本。

## 计时

- 三种时钟形态：圆环、翻页、常态倒计时，随时切换，字号按时长位数自适应
- 倒计时与正计时并存；内置经典番茄钟、深度专注、学习休息、考试模式、正计时五种模板，也可以自建模板或直接选一个临时时长
- 专注与休息首尾相接，阶段结束自动开始下一段，不用每轮重新点开始（可在设置里关掉）
- 随时点「结束本段」，把已用时间计入统计后接续下一段；「重置」清零当前阶段，「跳过」不计入本段用时

## 记录与统计

- 任务清单：标题、备注、预估段数，完成的专注段自动累加到任务进度
- 今日 / 区间 / 完成段数 / 平均时长四个指标，配每日时长柱状图、完成段数折线图与模板占比环形图
- 导出 JSON 完整备份与 CSV 记录表（带 BOM，Excel 直接打开不乱码）

## 体验

- 沉浸模式：自动全屏，顶部常驻当前时间与日期，控制栏静止后自动隐藏
- 阶段结束有提示音，应用不在前台时额外发系统通知
- Windows 11 专注助手免打扰，可设本应用提醒白名单
- 应用内更新：启动时检查新版本，弹窗列出更新内容，确认后下载安装并自动重启
- 青灯标识与应用名均为中文，亮暗两套主题
- Android 平板版：按宽度在侧边栏、图标栏、底部导航之间切换，触控区域自动放大
