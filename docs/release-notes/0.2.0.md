# 青灯 v0.2.0

第一个通过 GitHub Releases 分发的版本。更新包从 jsDelivr 下载，国内不用直连 GitHub，
装好这一版之后，以后有新版本会自己提示。

## 改进

- 设置页的「关于与更新」重做：显示当前版本、检查更新、反馈入口，并说明记录只保存在本机
- 设置页的主题说明改得更直白，不再出现「答辩」「数据库」这类和普通使用无关的措辞
- 统计页与模板弹窗里指向「本地数据库」的说法统一改成「这台设备」

## 保持不变

- 三种时钟形态、五种内置模板、任务清单、统计与导出都跟 0.1.0 一样
- 专注与休息自动接续、随时「结束本段」并计入用时，也都没变

## 已知问题

- 数据还不能导入，换设备可以先用「导出完整备份」留档
- Android 版不支持应用内更新，需要下载安装包覆盖安装
