# 青灯 v0.3.0

这一版的重点在安卓：平板不再是一套缩小版的后台管理界面，手机也能正常用了。

## 新增

- 手机适配：底部导航、单手够得着的控制条、统计记录改成卡片列表
- 下载页 https://soulmte.github.io/qingdeng/ ，打开会自动填上最新版号和下载地址

## 改进

- 平板上的导航收成左侧一条图标竖栏。此前横屏平板（普遍 1280px 以上）会被当成宽屏桌面，直接出现 224px 的侧边栏，整页看上去像一套后台系统
- 计时页的标题栏与控制条按屏幕宽度重排：手机上模板与任务按钮平分一行，开始按钮单独一行，重置与跳过收成图标
- 设置页在手机上改成上下排列，控件单独一行，按钮占满宽度
- 弹窗在手机上贴底展开，长内容可以滚动
- 三种时钟的字号改按容器宽度缩放，手机横竖屏切换都不会顶出圆环
- 统计页的柱状图在手机上给了最小高度，此前柱子与纵轴标签会挤成一团

## 保持不变

- 记录格式、模板、任务与导出方式都与 0.2.1 一致，覆盖安装不会丢数据
- 桌面端的布局没有变化

## 已知问题

- 数据还不能导入，换设备可以先用「导出完整备份」留档
- Android 版不支持应用内更新，需要下载安装包覆盖安装
