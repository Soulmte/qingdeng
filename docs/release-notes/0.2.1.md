# 青灯 v0.2.1

这一版把更新提示和圆环钟重新做了一遍，并修好了安卓平板上的桌面图标。

## 改进

- 更新提示弹窗加宽，更新说明按小节和条目分行，不再挤成一条窄柱
- 下载更新时显示真实进度：已下载 / 总大小、百分比和当前速度；拿不到总大小时改为来回滚动的提示条
- 圆环钟重新设计：外圈排上 60 格刻度并收一条细表壳线，进度弧改用渐变，弧头带一个跟着走的光点
- 刻度与内圈细线改用单独的颜色，浅色主题下也能看清

## 修复

- 修复安卓平板上桌面图标显示为默认图标的问题，现在与桌面端是同一盏青灯

## 保持不变

- 三种时钟形态、五种内置模板、任务清单、统计与导出都和 0.2.0 一样
- 专注与休息自动接续、随时「结束本段」并计入用时，也都没变

## 已知问题

- 数据还不能导入，换设备可以先用「导出完整备份」留档
- Android 版不支持应用内更新，需要下载安装包覆盖安装
